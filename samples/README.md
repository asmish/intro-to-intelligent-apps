# Sample Data and Payloads

This directory contains sample data structures, JSON payloads, and examples that can be used for building intelligent applications that integrate with various Azure services.

## Azure Update Manager Webhooks

- [post-maintenance-webhook.json](azure-update-manager/post-maintenance-webhook.json) - Sample webhook payload for post-maintenance events from Azure Update Manager

## Usage

These samples are intended to help developers understand the structure of data they might receive from Azure services when building intelligent applications that need to process and analyze service events.
